#  Proyecto APT – Sistema de Gestión Académica (Intranet)

##  Descripción del Proyecto  
El Proyecto APT consiste en el diseño e implementación de una solución informática para el **Colegio San Agustín de Hipona**, cuyo objetivo principal es centralizar y optimizar la gestión de información académica.  

Actualmente, los registros se manejan en planillas dispersas, lo que dificulta su **control, actualización y análisis**.  
La propuesta plantea migrar estos datos hacia una **base de datos relacional** y construir un sistema que permita acceder a la información de forma **segura, escalable y organizada**.  

Este proyecto responde a la creciente necesidad de **digitalización de procesos en el ámbito educativo**, contribuyendo a la eficiencia en la gestión administrativa y académica.  

##  Objetivos  
- **General:**  
  Diseñar e implementar un sistema de gestión académica que centralice los registros del colegio, mejorando el control y la disponibilidad de la información.  

- **Específicos:**  
  - Migrar los registros desde planillas a una **base de datos estructurada**.  
  - Desarrollar una **aplicación backend** que permita consultas y operaciones sobre la información.  
  - Implementar funcionalidades para **gestión de alumnos, profesores, apoderados y pagos**.  
  - Asegurar que el sistema sea **escalable, seguro y mantenible**.  



##  Tecnologías  
- **Lenguaje principal:** HTML/CSS/JAVASCRIPT
- **Framework:**   DJANGO
- **Base de datos:** POSTGRESQL/SQLITE
- **Control de versiones:** Git, GitHub, drive, live server, trello


##  Funcionalidades  
- **Alumnos:** Registro, edición, notas, asistencia y asignaturas.  
- **Apoderados:** Visualización de información académica de sus hijas y pagos.  
- **Profesores:** Administración de cursos y registro de notas.  
- **Administración:** Control de usuarios, pagos realizados y atrasados.
